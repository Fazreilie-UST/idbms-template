# Program Manager Guide

Program Managers (PMs) own the build plan lifecycle and approve build
requests from requestors.

## Typical workflow

1. **Create or import a build plan** under *My Build Plans*. Excel imports
   are supported through *Administration → Import Build Plan*.
2. **Grant access** to requestors who should be able to submit build
   requests against the plan.
3. **Review build requests** as they arrive in *Manage Build Requests* and
   approve, reject or hand off to the Coordinator.
4. **Track shipments** to verify that approved requests reach their
   destination warehouses.

## Reports

- The PM dashboard summarises open plans, pending requests and shipment
  status. Use the date filters to focus on a specific quarter or program.
