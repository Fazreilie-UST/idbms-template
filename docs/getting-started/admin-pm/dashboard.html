Display analytics summaries of build plan information based on the data stored in the database.

The dashboard contains 2 primary views:

  • My Build Plans
  • Overview

My Build Plans

A standardized dashboard populated using build plans managed by the current Program Manager (PM).

Features

  • Filterable by Family Code (Default filter: Displays all data including "cancelled" build config)

Overview

A standardized dashboard populated using all build plan data available in the database.

Features

  • Filterable by Year, Family, Form Factor, Status Code (Default filter: Displays all data excluding build configs with "cancelled" status)
  • Generic toggle quantity display between: Builds (Configs) and Boards (Build Requests + Quantity stored in warehouse)
