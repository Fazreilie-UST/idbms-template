# Requestor Guide

Requestors create build requests against build plans they have been granted
access to.

## Submitting a build request

1. Go to *My Build Requests* and click **New Request**.
2. Choose the build plan and revision you are requesting against.
3. Specify quantities, destination warehouse and any special handling
   notes.
4. Submit. The owning Program Manager will receive the request in their
   queue.

## Tracking progress

- Use the **Build Request Tracker** to follow the status of every request
  you have submitted.
- The **Shipment Tracker** shows downstream shipment information once the
  request has been fulfilled.
