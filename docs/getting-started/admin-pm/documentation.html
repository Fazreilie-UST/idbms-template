This page provides guidance on how to use and contribute to the documentation for the NPI DBMS platform.

Editing Documentation

  • All documentation is now written and edited in HTML format for maximum flexibility and asset support.
  • Use the HTML editor in the application to make changes, insert images, and manage assets.
  • Refer to the Documentation Assets modal (by clicking the "insert image" button in edit mode) to upload, preview, and insert images.

Contributing

  • Follow the structure and style of existing documentation pages.
  • Use semantic HTML elements (headings, lists, tables, etc.) for clarity and accessibility.
  • Keep content up to date and relevant for all user roles.
