# Screen Guide


![mclaren-w1-8k-7680x4320-c0148b49134a.jpg](/static/docs-assets/screenshots/mclaren-w1-8k-7680x4320-c0148b49134a.jpg)


This guide walks through each screen of the NPI DBMS application and how to
use it.

## Navigation overview

- **Dashboard** – KPI snapshot for your role.
- **Build Plans** – Create, view, and manage build plans (Program Manager).
- **Build Requests** – Submit and track build requests against approved plans.
- **Shipments** – Track shipment status and recipient information.
- **Trackers** – Read-only views shared across roles for searching plans,
  requests, and shipments.
- **Administration** – User, role and reference-data management (Admin /
  Program Manager).
- **Documentation** – You are here.

## Tips

- Use the role indicator in the top-right of the page to confirm which role
  you are currently signed in as.
- Most tables support column filters and CSV / PDF export from the toolbar.
- Use the global search in each tracker page to locate records across all
  programs.
