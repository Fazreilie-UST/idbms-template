Program Managers (PMs) own the build plan lifecycle and approve build requests from requestors.

Typical workflow

  1. Create or import a build plan under My Build Plans. Excel imports are supported through Administration → Import Build Plan.
  2. Grant access to other Program Manager who should be able to submit handle the build plan. Access level can be determine either for a specific build config, or for the whole family product. In general, a PM will only handle one product family
  3. Review build requests as they arrive in Manage Build Requests and approve, reject or hand off to the Coordinator.
  4. Submit Build Plan to ODM.
  5. Track shipments to verify that approved requests reach their destination warehouses.

Reports

  • The PM dashboard summarises open plans, pending requests and shipment status. Use the date filters to focus on a specific quarter or program.
